# Day 6 - Data Visualization with Matplotlib

## Concepts Covered

| Concept | Description |
|---|---|
| **Scatter Plot** | Visualizing relationship between study hours and scores |
| **Bar Chart** | Displaying average scores by hour ranges |
| **Line Chart** | Showing score trends across sorted study hours |
| **Subplots** | Creating combined multi-chart visualizations |
| **Customization** | Colors, labels, titles, grid, legends, annotations |

## Output Files

- `scatter_hours_vs_scores.png` - Scatter plot of Hours vs Scores
- `bar_avg_score_by_hours.png` - Bar chart of average scores by hour range
- `line_score_trend.png` - Line chart of score trend
- `combined_visualization.png` - All charts in a 2x2 grid

## How to Run

```bash
cd "day 6"
python main.py
```
