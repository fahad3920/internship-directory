# Day 5 - Data Cleaning

## Concepts Covered

| Concept | Description |
|---|---|
| **Missing Values** | Detecting with `isnull()`, handling with `fillna()` and `dropna()` |
| **Duplicate Removal** | Finding with `duplicated()`, removing with `drop_duplicates()` |
| **Statistical Analysis** | `describe()`, `median()`, `mode()`, `var()`, correlation |
| **Data Export** | Saving clean dataset to CSV |

## How to Run

```bash
cd "day 5"
python main.py
```
